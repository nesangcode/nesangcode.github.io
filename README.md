# Portfolio Website

This is a portfolio website designed for a full-stack developer to showcase skills, projects, and contact information.

## Project Structure

```
portfolio-website
├── assets
│   ├── css
│   │   ├── main.css        # Main styles for layout, typography, and color schemes
│   │   └── responsive.css   # Styles for responsive design
│   ├── js
│   │   └── script.js       # JavaScript for interactive features
│   └── fonts               # Custom font files
├── images                  # Image assets
├── pages
│   ├── about.html          # About page with developer's background and skills
│   ├── projects.html       # Projects page showcasing work
│   └── contact.html        # Contact page with a form and social media links
├── index.html              # Main entry point of the website
└── README.md               # Project documentation
```

## Features

- Responsive design for optimal viewing on various devices
- Interactive elements powered by JavaScript
- Sections for About, Projects, and Contact information

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd portfolio-website
   ```
3. Open `index.html` in your web browser to view the website.
